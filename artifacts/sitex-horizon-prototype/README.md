# Sitex Horizon – Live Bus Monitoring Prototype

**Glassmorphic Real-Time Bus Tracking & Public Announcement System**  
For Sitex (Sorsogon City Integrated Transport Exchange / SM Sorsogon)

## How to Run

1. Extract the ZIP file.
2. Open `index.html` in any modern browser (Chrome, Edge, Firefox recommended).
3. No installation or server needed – pure HTML/CSS/JS.

## Pages Included

| File                      | Description                                      |
|---------------------------|--------------------------------------------------|
| `index.html`              | Main Public Terminal Display (big screen view)   |
| `passenger.html`          | Passenger Phone / PWA View                       |
| `driver.html`             | Driver / Conductor Mobile App                    |
| `admin.html`              | Admin Dashboard + Live Announcements Editor      |
| `report.html`             | Passenger Report Form                            |

## Features in this Prototype

- Glassmorphic design (frosted glass, soft glow, teal accents)
- Live mock bus tracking on map
- Huge Live Announcement panel (Critical / Caution / Info)
- Editable announcements from Admin page
- Passenger Report button → simulated send to Sitex + Cooperatives
- Night mode toggle
- Responsive (works on PC and phone simulation)
- Mock real-time updates every few seconds

## Notes

- All data is simulated for demonstration.
- In real system this would connect to GPS phones + backend.
- Designed for public viewing at Sitex terminal screens.
