Sitex Horizon

Live bus arrivals for the Sorsogon Integrated Terminal Exchange. Phone GPS updates speed and ETA for all 16 municipalities.

This GitHub Pages address is not the live board

GitHub Pages only hosts static files. Sitex Horizon is a live app (GPS, database, driver confirm). It cannot run here — that is why you saw 404 File not found.

How to open the working website

  1. Go back to Grok Build (this project).
  2. Tap Publish at the top of the screen.
  3. Grok will give you a real HTTPS link you can open on a phone and send to SM Sorsogon.

Until then, use the live preview inside the Grok chat — Terminal, Passenger, Driver, Report, Control.
